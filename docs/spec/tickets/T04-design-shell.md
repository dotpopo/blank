# T04 · 设计系统与应用外壳

| | |
|---|---|
| 依赖 | T01(仅为了知道有哪些数据可展示) |
| 阻塞 | T05, T06, T07, T08 |
| 预估会话数 | 1 到 2 |

## 目标

定下**视觉与交互的语法**,之后所有页面只是这套语法的组合。
这一步没做扎实,后面每张工单都会各写各的,最终变成一堆互不相干的卡片。

## 前置动作(不可跳过)

1. 写**设计读法**一行(页面类型 / 受众 / 调性 / 设计体系)。
2. 显式设定三个旋钮 `DESIGN_VARIANCE` / `MOTION_INTENSITY` / `VISUAL_DENSITY`。
3. 只在**用户明确要求**配色方向时,才先问再做;否则按设计读法自行决定并说明理由。

## 交付物

- [ ] `src/styles/tokens.css`(或 Tailwind theme 扩展): 颜色、字阶、间距、圆角、阴影、动效时长。
      **不使用 Tailwind 默认调色板**,必须是有意图的取值。
- [ ] 字体策略: 中文字体栈明确(不默认 Inter),标题与正文的关系明确。
- [ ] 布局外壳: `src/layouts/` 下一个 `AppShell`(页头、导航、页脚、主内容区宽度约束)。
- [ ] 四个**状态原语**: 加载 / 空 / 错误 / 额度耗尽。每个都是组件,后续页面复用。
- [ ] 基础控件: `Button`(含 primary/secondary/disabled/loading)、`Input`、`Modal`、`Toast`。
      全部带 `:focus-visible` 与 aria 属性。
- [ ] 导航: `/` 首页、`/dashboard` 大盘、`/admin` 后台。移动端折叠方案明确。
- [ ] 一个 `/kitchen-sink` 或 Storybook 式的**临时页面**,把所有原语铺出来看一遍(交付后可删)。

## 反 AI 味硬性约束

- **破折号 `—` / `–` 零容忍**(中文里 `——` 同样算)。断句用句号、逗号、冒号。
- 不要三张等宽特性卡;不要居中大标题配渐变光斑;不要 AI 紫渐变;不要整站玻璃拟态。
- 不要每节挂一个 `uppercase tracking` 的装饰性小标签。
- 不要假数据(禁止 `99.99%`、`John Doe`、`Acme`、`Elevate/Seamless/Unleash` 这类)。
- 不要 div 拼的假截图;不要手搓 SVG 图标(模板自带 `lucide-react`,用它)。
- 动效强度 > 3 时,`prefers-reduced-motion` 必须处理。
- 按钮文字与底色对比度达 WCAG AA。

## 验收

- 所有原语在 320 / 768 / 1280 三个宽度下都不溢出、不重叠。
- 键盘可以走完所有交互控件,Tab 顺序合理,焦点可见。
- 打开系统「减弱动态效果」后,没有任何持续动画。
- 对比度用工具实测(不是目测)通过 AA。

## 不做什么

- 不写业务逻辑。
- 不做首页/大盘的具体内容(那是 T05/T08)。
