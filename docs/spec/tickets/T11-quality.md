## 目标

把「能跑」推到「能拿出去给人看」。
这一张工单不新增功能,**只做减法、做修正、做验证**。

## 交付物

- [ ] **反 AI 味预检**逐项打勾(见下),不通过不算完成
- [ ] **无障碍**: 键盘全流程、焦点可见、`aria-live` 播报、对比度实测 AA、语义标签正确
- [ ] **动效**: `prefers-reduced-motion` 下无持续动画;
      `requestAnimationFrame` 循环有取消句柄 + 后台暂停(`visibilitychange`)+ 卸载清理
- [ ] **响应式**: 320 / 390 / 768 / 1280 / 1920 五档实测
- [ ] **性能**: 首屏体积、字体加载策略、图片策略(本项目几乎没有图片,不要引入)
- [ ] **文案通读**: 所有面向用户的文字过一遍,删掉废话、删掉「赋能/一站式/极致体验」这类词
- [ ] **空态/错态/边界态**: 全部页面走一遍,确保没有「白屏 + 控制台报错」
- [ ] **收尾干净**: 删掉临时页面(`/kitchen-sink`)、注释掉的死代码、调试用 console
- [ ] 更新 `README.md` 与 `AGENTS.md` 到与实现一致

## 反 AI 味预检清单

- [ ] 全文无 `—` / `–` / `——`
- [ ] 没有三张等宽特性卡
- [ ] 没有居中大标题配渐变光斑
- [ ] 没有 AI 紫渐变
- [ ] 没有整站玻璃拟态
- [ ] 没有默认 Inter 当正文字体
- [ ] 没有每节一个的 `uppercase tracking` 装饰标签
- [ ] 没有假数据(`99.99%` / `John Doe` / `Acme` / `Elevate` / `Seamless` / `Unleash`)
- [ ] 没有 div 拼的假截图
- [ ] 没有手搓 SVG 图标(用 lucide-react)
- [ ] 三个旋钮的取值与实际实现一致

## 验收

- 上面每一项都打过勾,有**实测证据**(工具输出、截图、或数字),不是「我看过了」。
- `npm run build` 通过,`npm run test:e2e` 全绿。
- 在**真实的窄屏设备或 DevTools 设备模式**下走一遍完整领取流程。

## 不做什么

- 不加新功能。发现缺陷 → 记下来,单独开工单。
- 不做 SEO / 不做分析埋点(除非用户要求)。
